Documentation ? bsic-service

Vue d’ensemble

Service Spring Boot pour la gestion de l’annuaire (directions, services, departements, agences, employes), de l’habilitation (plateformes, circuits, fiches, etapes), des reunions, et la generation de rapports PDF.

Stack technique

  • Java 17
  • Spring Boot 3.5.3 (Web, Data JPA, Validation, Security, Actuator)
  • PostgreSQL
  • MapStruct
  • JWT (jjwt)
  • Spring Mail + Thymeleaf
  • JasperReports
  • Springdoc OpenAPI (UI)

Lancement

Port par defaut: 8083

Profil dev (securite ouverte)

mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=dev

Profil prod (JWT + securite)

mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=prod

Build

mvnw.cmd clean package

Configuration

Fichiers: - src/main/resources/application.yml (commun) - src/main/resources/application-dev.yml - src/main/resources/application-prod.yml

Base

  • server.port: 8083
  • spring.profiles.active: prod
  • app.storage.path: ./datas (stockage fichiers)

DB

Profil dev: - jdbc:postgresql://localhost:5432/categoriedb

Profil prod: - jdbc:postgresql://localhost:5432/categorie_db

Mail

Configurer via spring.mail.* dans application.yml.

Securite

  • Profil dev: toutes les requetes sont permises, CORS/CSRF desactives.
  • Profil prod: JWT + stateless, certaines routes publiques (auth, activation, CSRF, etc.), le reste authentifie.

Stockage fichiers

Service: BaFileStorageService - Lecture par id dans app.storage.path. - Sauvegarde genere un id (UUID) et ecrit le fichier. - Suppression logique par suppression du fichier.

Rapports

Service: BaReportService - Fiche habilitation: reports/fiche-habilitation.jrxml. - Fichiers generes dans ./target.

APIs

Base URL: /api
